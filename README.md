- **[Remi](https://github.com/Friasru/Remi)** — Windows reminders and calendar app built with React and Tauri. [Download the Windows installers](https://github.com/Friasru/Remi/releases).
- **[ATCS Monitor](https://github.com/Friasru/ATCS-Monitor)** — Webcam-based vehicle and pedestrian counting using YOLO and ByteTrack.
- **[Budgy](https://github.com/Friasru/Budgy)** — Browser-based budget app with local data storage.
