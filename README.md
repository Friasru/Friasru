<summary>How did the ATCS controller perform?</summary>

In one SUMO scenario, average vehicle wait fell from **13.39 s** with fixed signal timing to **3.74 s** with the wait-time controller, a **72% reduction**. The controller reads vehicle wait times and updates signal phases through TraCI.
